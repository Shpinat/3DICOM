# DICOM Просмотрщик

Прогрессивное веб-приложение (PWA) для просмотра медицинских DICOM файлов.
Поддерживает 2D-просмотр, мультипланарную реконструкцию (MPR) и 3D визуализацию.

## Функционал

- Загрузка DICOM файлов (перетаскивание или через выбор файлов)
- 2D-просмотр (Cornerstone.js) с поддержкой:
  - Панорамирования и масштабирования
  - Настройки Window/Level
  - Прокрутки срезов колесиком мыши
- Браузер загруженных серий
- Поддержка PWA (работа оффлайн, установка как приложения)
- Страницы для MPR и 3D (интерфейсные заглушки/базовая визуализация)

## Стек технологий

- React + TypeScript
- Vite
- Cornerstone.js (core, tools, math, wado-image-loader)
- Three.js
- TailwindCSS

## Запуск проекта

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск локального сервера для разработки

```bash
npm run dev
```

Откройте `http://localhost:5173` в вашем браузере.

### 3. Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут находиться в папке `dist`.

## Деплой на GitHub Pages

Проект настроен на автоматический деплой через GitHub Actions. При пуше в ветку `main`, сработает workflow, который:

1. Установит зависимости
2. Соберет проект
3. Загрузит содержимое папки `dist` в ветку `gh-pages`

Ваш сайт будет доступен по адресу: `https://<ваше-имя-пользователя>.github.io/dicom-viewer/`. Убедитесь, что в настройках репозитория (Settings -> Pages) в качестве источника выбрана ветка `gh-pages`.
